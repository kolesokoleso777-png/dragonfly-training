Dragonfly Izakaya — обучение персонала (v7)

ЗАЛИТЬ: перетащите ВСЮ папку на Netlify Drop (папка cards/ обязательна).
ОБНОВИТЬ НА ТЕЛЕФОНЕ: удалить старую иконку, открыть ссылку, установить заново.
Если пусто: Ещё -> «Очистить кэш и перезапустить» (или на экране ошибки).

РОЛИ
- Менеджер: на экране входа «Я менеджер» -> регистрация (один раз), дальше вход по паролю.
- Сотрудник: менеджер добавляет его (имя, фамилия, телефон, возраст, галочки), получает код и ссылку для WhatsApp.
- Свободный вход без регистрации отключён. Доступ только менеджеру по паролю и сотруднику по коду.
ДЕМО: данные пока хранятся на телефоне. Общий список и прогресс между телефонами заработают после подключения Cloudflare.

v7: шкала «Бар» (вина / ассортимент / коктейли), регламент текстом (вкладка «Контент» -> «Регламент»), вопросы «верно/неверно», выбор ответа и свои вопросы.

v8: защита от обмана (10 выходов за 15 минут во время теста -> блокировка и обжалование), водяной знак, затемнение при сворачивании, запрет копирования, кнопка «Отключить доступ». Основа: архив dragonfly-training-v7-no-free-login.

v9
- Блокировка из-за сворачиваний закрывает только сдачу тестов. Учить меню, сервис и регламент можно.
- Экран «Как открыть сдачу»: сделать скриншот открытых приложений и отправить менеджеру в WhatsApp/Telegram.
- Дашборд менеджера: подозрительные сотрудники сверху, красные и мигают, красная точка на вкладке «Сотрудники».
- Контакты WhatsApp/Telegram у менеджера и сотрудника, приглашение отправляется кнопкой.
- Условия использования: для менеджера при регистрации, для сотрудника при первом входе, кнопка в «Ещё».

v10
- Встроено барное меню (bar.js + cards/bk.js): коктейли «Кимоно» (7 фото), авторские, классика с граммовкой, лимонады, чаи, матча, листовой чай, кофе, сакэ, соджу, водка, ром, текила, джин, виски, коньяк, безалкогольное.
- Вопросы по бару: бокал, метод, гарнир, граммовка, «какой напиток описан так», история кимоно.
- Кухня обновлена по новому тексту: Бонито, Хрустящая креветка, Рулетики татаки, Татаки, салаты (страчателла, водоросли, угорь), тартары, овощи темпура, Кушияки креветки (лангустины), Рис кимчи, Чизкейк, Моти, Роти; добавлены Спринг-роллы с курицей и овощами.
- Менеджер: «Ещё» → «Удалить мой профиль» (пароль, выбор: только профиль или всё заведение).
- Сервис: «Одобрить» доступно после прочтения всех разделов и галочки «принимаем эти правила для обучения сервису наших сотрудников»; сохраняются имя и время.
- Исправлено: sw.js в v9 был пустым (нет офлайн-кэша).
Загрузка на Cloudflare: распаковать, загрузить содержимое папки целиком (вместе с cards/).
